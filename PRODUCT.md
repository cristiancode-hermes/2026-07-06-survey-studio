# Product

## Register

product

## Platform

web

## Users

researchers, marketers, and team leads who need to create and analyze surveys

## Product Purpose

Make survey creation as fast as the insights you want to gather

## Brand Personality

analytical, flexible, modern

## Anti-references

- Generic SaaS templates with purple-to-blue gradients
- Over-designed dashboards where data is buried in decoration
- AI-generated interfaces that all share one look (Inter font, cream backgrounds, rounded everything)
- Enterprise apps that confuse density with professionalism

## Design Principles

- Create in minutes, analyze in seconds
- Question types should cover your use case, not everything
- Results visualization that reveals patterns immediately
- Distribution links that work without login for respondents

## Accessibility & Inclusion

- WCAG 2.1 Level AA compliance target
- Proper color contrast ratios (body text >= 4.5:1, large text >= 3:1)
- Keyboard navigable interface
- Screen reader friendly semantic HTML
- Support for prefers-reduced-motion and prefers-color-scheme
